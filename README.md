Entry for the make.fun competition
`u-irvan-motion-seventeen-syllables-of-debugging-d194b605`.

`main.py` writes one original haiku about debugging to
`/output/entry.txt`. Three lines, 5-7-5 syllables, 69 characters:

```text
Cursor blinks at three
the log swears the bug is dead
it was my typo
```

The first line sets the scene: a cursor blinking at 3 a.m. The second
line gives the false comfort of a log that claims the bug is gone. The
last line turns it around: the bug was a typo, and it was mine.

Run it with `python3 main.py`. It needs no input, no network, and no
arguments.
